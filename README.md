\# TP Java Servlet, Filters, Listeners et JSP



\## Présentation



Ce dépôt contient les travaux pratiques réalisés dans le cadre du cours de développement Web avec Java et Jakarta EE.



Le TP est organisé en deux parties principales.



\## Partie 1 : Servlets, Filters et Listeners



Cette partie porte sur :



\- Les Servlets et le traitement des requêtes HTTP.

\- Les méthodes `doGet()` et `doPost()`.

\- Les formulaires HTML.

\- La gestion des cookies.

\- La gestion des sessions.

\- Les Filters : journalisation et sécurité.

\- Les Listeners : événements liés à l'application et aux sessions.



\## Partie 2 : JSP, JavaBeans et MVC



Cette partie porte sur :



\- Les expressions JSP.

\- Les Scriptlets.

\- Les déclarations JSP.

\- La création et l'utilisation des JavaBeans.

\- Les actions JSP : `useBean`, `setProperty` et `getProperty`.

\- L'architecture MVC : Model, View et Controller.

\- Le transfert des requêtes avec `RequestDispatcher` et `forward()`.



\## Technologies utilisées



\- Java 17

\- Jakarta Servlet 6.0

\- Apache Tomcat 11

\- JSP

\- HTML
